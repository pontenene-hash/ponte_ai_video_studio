# PONTE AI Video Studio v1.2

Google Flowで生成した6本の動画を、iPhoneからアップロードして字幕・BGM付きの30/45/60秒MP4に結合する半自動Streamlitアプリです。

## GitHubへの登録
1. GitHubで新しいリポジトリ `ponte-ai-video-studio` を作成。
2. `app.py`, `requirements.txt`, `packages.txt`, `.streamlit/config.toml` を同じ構成でアップロード。
3. https://share.streamlit.io/ を開き、Create app → GitHub repositoryを選択。
4. Main file path に `app.py`、Python 3.12を指定しDeploy。
5. 発行されたURLをiPhone Safariで開き、共有→ホーム画面に追加。

## 使い方
1. ①企画でジャンル・テーマ・対象・動画時間を入力し、構成を作成。
2. ②プロンプトで6シーンの文章・字幕を修正。Google Flowへコピーし、各8秒のMP4を保存。
3. ③素材・編集で各MP4と任意のBGMをアップロード。結合ボタンを押す。
4. ④完成・保存でプレビューしMP4をダウンロード。

## 注意
- 台本はテンプレート生成で、外部AI API料金は不要。Google Flowの生成は手動です。
- 6本の動画を結合するため、短い動画は最後のフレームを静止させて長さを合わせます。
- 端末やCloudの容量・メモリ制限で高解像度素材の結合に失敗することがあります。720p程度の短い素材推奨。
- 動画・制作履歴はサーバーに永続保存しません。ブラウザの再読込やセッション終了時に消える場合があります。
- BGMは商用利用が認められたものを使ってください。
- 医療広告表現、運動フォーム、AI生成施術描写は公開前に確認してください。

## v1.1：1日50クレジット以内の分割制作

1. 「① 企画」でジャンル・テーマを決め「6シーンの構成を作成」を押す。
2. 「② 日別制作計画」で1日の利用可能クレジット（初期値50）と8秒動画1本の単価（初期値10）を設定する。実際のFlow画面に表示される値が優先。
3. 開始日を選ぶと、6シーンを日付ごとに自動配分する。初期設定なら初日に5シーン（50cr）、翌日に1シーン（10cr）。
4. 「③ Flowプロンプト」から当日分のプロンプトをコピーし、Google Flowで動画を作ってiPhoneに保存。
5. 完了したシーンは「② 日別制作計画」でチェック。計画と進捗はJSON/CSVで保存可能。
6. 全シーン完成後、「④ 素材・編集」で6本をアップロードし「⑤ 完成・保存」で完成MP4を確認・保存。

**注意**：Google Flowとは残高・生成履歴を自動同期しません。チェック状態はStreamlitセッション内のみで、再読み込みやスリープで失われる場合があります。日別計画JSONを保存して記録してください。生成失敗・再生成時も消費クレジットを確認してください。無料枠の提供・モデル単価は変更される場合があります。

### GitHub更新方法
既存リポジトリの `app.py` と `README.md` をZIP内の新版に置き換えてコミットすると、Streamlit Community Cloudで再デプロイされます。`.streamlit/config.toml`、`packages.txt`、`requirements.txt` は維持してください。

## v1.2：1日3シーン・2日で6シーン

- 初期設定（50cr/日・10cr/クリップ）で、1日目シーン1〜3（30cr）、2日目シーン4〜6（30cr）に割り当てます。
- 日ごとに最大3シーンまで。残り20crは再生成などの予備ですが、実際の残高を保証するものではありません。
- クリップ単価が高く、50crで3本作れない場合は自動的に1日あたりの本数を減らします。
