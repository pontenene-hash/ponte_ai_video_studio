# PONTE AI Video Studio v1.5

iPhone対応のGoogle Flow半自動動画制作アプリです。Streamlit Community Cloudで利用できます。

## 変更点
- 「⑥ 保存・再開」画面を追加。`PONTE_project_YYYYMMDD.zip` をダウンロードして中断できます。
- ZIPを再アップロードすると、企画設定・6シーンのプロンプト・字幕・日別進捗・動画素材・BGM・完成MP4を復元できます（ZIP作成時に「動画素材も含める」がオンの場合）。
- 旧 `ponte_prompts.json`（台本）と `ponte_daily_plan.json`（進捗）も読み込み可能です。旧JSONには動画素材は含まれません。
- iPhoneでJSONのプレビューが開く問題を避けるため、作業の保存はZIP方式を推奨します。ただしiOSのダウンロード表示・ブラウザの挙動自体をアプリから強制変更することはできません。
- アップロードした各シーン動画とBGMをセッション中に保持し、復元後も個別プレビューできます。
- 1日目3シーン・2日目3シーン、1日50クレジット計画、コピー、日本語字幕、BGM、MP4結合を維持。

## GitHub / Streamlit Cloud導入
1. ZIPを解凍し、`app.py`, `requirements.txt`, `packages.txt`, `README.md`, `.streamlit/config.toml` をGitHubリポジトリのルートにアップロード。`__pycache__` は不要です。
2. Streamlit Community Cloudでリポジトリを指定し、メインファイル `app.py` を選択してデプロイ。
3. iPhoneのSafariでアプリを開いて利用します。

## 保存・再開
1. 作業を中断する前に「⑥ 保存・再開」を開きます。
2. 「動画素材・BGM・完成MP4もバックアップに含める」を必要に応じて選択します。
3. 「バックアップファイルを準備」→「作業バックアップ（ZIP）を保存」。iPhoneの「ファイル」アプリ内に保存してください。
4. 次回「⑥ 保存・再開」→「以前保存したZIPまたは旧版JSONを選択」→「このファイルから作業を復元」。
5. 企画・日別計画・プロンプト・素材の各画面に戻って作業を続けます。

## iPhoneのダウンロード画面について
SafariやiOSのファイルプレビューはStreamlitから完全には制御できません。JSONを直接開かずZIPで保存することでプレビューへの移動を減らします。もしプレビュー画面に移った場合はSafariの元のタブに戻ってください。ChatGPT内ブラウザではなくSafariからアプリURLを開くことを推奨します。

## 注意事項
- 無料Streamlit Cloudではファイル容量・メモリ・実行時間の制限があります。大きな動画を含むZIPの復元やMP4結合が失敗する場合があります。
- バックアップZIPには動画素材を含むため、個人情報や患者映像の取扱いに注意してください。患者の実写素材は同意が必要です。
- Google Flowのクレジット残高とは同期しません。実際の料金・残高はFlow側で確認してください。
